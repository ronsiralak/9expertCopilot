# Neon MCP

- Use the Neon MCP server configured in `.vscode/mcp.json` to query and
  interact with the database from an agent in VS Code.
- Start the server in VS Code and authorize the Neon account with OAuth.
  Verify access by asking the agent to list tables on a development branch.
- Neon recommends MCP for development and testing, not production. Review
  requested actions before authorizing them.
