# Bucks2Bar

เว็บแอปแบบ static สำหรับบันทึกรายรับและรายจ่ายรายเดือนเพื่อแสดงเป็นกราฟแท่ง โดยไม่ต้องติดตั้งหรือเปิดเซิร์ฟเวอร์

## เริ่มใช้งาน

1. เปิดไฟล์ [index.html](./index.html) ในเว็บเบราว์เซอร์
2. เชื่อมต่ออินเทอร์เน็ตเพื่อโหลด Bootstrap, Chart.js และ SheetJS จาก CDN
3. กรอกข้อมูลรายรับและรายจ่ายในแท็บ **Data**
4. เปิดแท็บ **Chart** เพื่อดูกราฟ ซึ่งอัปเดตอัตโนมัติเมื่อข้อมูลเปลี่ยน

ข้อมูลเริ่มต้นของทุกเดือนเป็น 0 และช่องที่เว้นว่างจะถูกนับเป็น 0 ในกราฟและไฟล์ Excel

## ฟีเจอร์

- กรอกข้อมูลรายรับและรายจ่ายตั้งแต่เดือนมกราคมถึงธันวาคม
- สลับธีมหน้าแรกด้วยปุ่ม ☀️/🌙 โดยเริ่มต้นที่ธีมมืดและไม่บันทึกค่าธีมเมื่อรีเฟรช
- ตรวจสอบ username: อย่างน้อย 5 ตัวอักษร โดยมีตัวพิมพ์ใหญ่ภาษาอังกฤษ ตัวเลข และอักขระพิเศษอย่างน้อยอย่างละหนึ่งตัว เช่น `User1!`
- หน้า [Register](./register.html) สำหรับกรอกชื่อ อีเมล รหัสผ่าน ยืนยันรหัสผ่าน และที่อยู่ พร้อมตรวจสอบว่ารหัสผ่านตรงกัน โดยเป็นแบบฟอร์มสาธิตและไม่ได้สร้างบัญชีจริง
- ดาวน์โหลดข้อมูลรายเดือนเป็นไฟล์ Excel ด้วยปุ่ม **Export to Excel**
- นำเข้าข้อมูลด้วยปุ่ม **Import Excel** จากไฟล์ `.xlsx` หรือ `.xls` โดยใช้แผ่นงาน `Monthly Data` (ถ้าไม่มีจะใช้แผ่นงานแรก) และคอลัมน์ `Month`, `Income`, `Expenses` ตามลำดับ ระบุชื่อเดือนภาษาอังกฤษเต็มตั้งแต่ January ถึง December ให้ครบเดือนละหนึ่งแถว ช่องจำนวนเงินต้องเป็นตัวเลขหรือเว้นว่าง ก่อนนำเข้าจะมีการยืนยันเพื่อแทนที่ข้อมูลทั้ง 12 เดือน
- ดาวน์โหลดกราฟเป็นภาพ PNG ด้วยปุ่ม **Download Chart**

ข้อมูลจะไม่ถูกบันทึกถาวรและจะหายเมื่อรีเฟรชหรือปิดหน้าเว็บ ควรส่งออกข้อมูลก่อนออกจากหน้าเว็บ

## โครงสร้างไฟล์

- [index.html](./index.html) — โครงสร้างหน้าเว็บและการโหลดไลบรารี
- [register.html](./register.html) — หน้าแบบฟอร์มลงทะเบียนสาธิต
- [style.css](./style.css) — รูปแบบเพิ่มเติมของหน้าเว็บ
- [script.js](./script.js) — จัดการข้อมูล กราฟ การส่งออก และตรวจสอบ username
